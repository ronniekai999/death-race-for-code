# README assets

`death-race-banner.svg` is an original vector brand illustration, not an app screenshot.

`legends-never-die-preview.png` and `righteous-preview.png` are unmodified output from
`DeathRace --render-chrome`, generated by the macOS CI run
[38085048125](https://github.com/ronniekai999/death-race-for-code/actions/runs/38085048125)
for source commit `849ac9ec861e845adf1cde43b9a773080cdc1c79` on 2026-10-10.

The runner used macOS 26.6.2, Xcode 26.6, Swift 6.3.3 and Apple's Paravirtual Metal device.
The verified chrome artifact SHA-256 was
`6ae3f13d7675b647e286ad1fa55c8368a786a04499fefa23aff6f358c10f85cb`.

These previews use scripted sessions and example hosts to show the workspace and command
status styling. Their failed-command output is a fixture, not the CI result. Window-server
traffic lights and blur effects are omitted by the preview renderer. Physical-display,
VoiceOver, Touch ID and privacy acceptance remain separate.
